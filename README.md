# Java Plane Shooting Game

A simple 2D plane shooting game built using Java Swing and AWT. This project demonstrates object-oriented programming, basic animation, threading, and event-driven interaction through a lightweight shooting game interface.

---

## Gameplay Overview

- Control a player plane to dodge and shoot down incoming enemy planes.
- Enemies spawn periodically and move down the screen.
- The player shoots bullets to destroy enemies.
- The game runs in a continuous loop with score tracking.

---

## Features

- Keyboard-based movement and shooting
- Collision detection between bullets and enemies
- Object-oriented class design (Player, Enemy, Bullet, etc.)
- Sprite-based rendering with PNG assets
- Thread-based animation and real-time updates

---

## Controls

| Key        | Action                          |
|------------|----------------------------------|
| D key | Move the plane (Up, Down, Left, Right)|
| Spacebar   | speeds up the plane              |
| K key        | shoots                   |
